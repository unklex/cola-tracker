# 📱 Cola Tracker - Полный Android проект готов!

## ✅ Что создано

### 🎨 Полноценное Android приложение на Kotlin + Jetpack Compose

**Технологии:**
- Kotlin (современный язык для Android)
- Jetpack Compose (декларативный UI)
- Ktor Client (HTTP клиент для API)
- MVVM архитектура (чистая структура кода)
- Material Design 3 (современный дизайн Google)

## 🚀 Быстрый старт

### 1. Распакуй архив
```bash
tar -xzf ColaTrackerApp.tar.gz
```

### 2. Открой в Android Studio
File → Open → выбери папку `ColaTrackerApp`

### 3. Подожди синхронизацию Gradle
(2-5 минут при первом запуске)

### 4. Запусти приложение
- Создай эмулятор (Pixel 6, API 34)
- Нажми **▶️ Run**

### 5. Тестируй!
По умолчанию работает в тестовом режиме с фейковыми данными.

## 🔧 Настройка для работы с реальным API

### Когда сын сделает бэкенд:

1. Открой `app/src/main/kotlin/com/colatracker/AppConfig.kt`

2. Измени:
```kotlin
const val USE_MOCK_DATA = false  // ← Переключи на false
const val BASE_URL = "http://192.168.1.XXX:8000"  // ← Твой IP
const val AUTH_TOKEN = "твой_токен_из_data.json"  // ← Токен
```

3. Перезапусти приложение

**Готово!** Теперь работает с реальным сервером.

## 🐛 Частые проблемы

### Gradle sync failed
→ File → Invalidate Caches → Restart

### Устройство не видно
→ Проверь USB кабель и драйверы

### Cannot connect to server
1. Сервер запущен?
2. IP правильный?
3. Телефон и комп в одной сети?
