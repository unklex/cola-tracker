# Cola Tracker - Android приложение

Мобильное приложение для отслеживания потребления Кока-Колы детьми.

## 📱 Возможности

- ✅ Просмотр списка детей с их лимитами
- ✅ Быстрое добавление записей (250 мл, 330 мл или свое количество)
- ✅ История потребления для каждого ребёнка
- ✅ Удаление записей с откатом счётчиков
- ✅ Накопительная система лимитов (неизрасходованное не сгорает)
- ✅ Тестовый режим с фейковыми данными
- ✅ Работа с реальным API сервером

## 🛠️ Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Архитектура:** MVVM
- **Сеть:** Ktor Client
- **Сериализация:** Kotlinx Serialization
- **Навигация:** Navigation Compose
- **Минимальная версия Android:** API 26 (Android 8.0)

## 🚀 Установка и запуск

### Шаг 1: Открыть проект

1. Запусти **Android Studio**
2. Выбери **"Open"** (или **"File" → "Open"**)
3. Найди папку `ColaTrackerApp` и открой её
4. Android Studio автоматически начнёт синхронизацию Gradle (подождите 2-5 минут)

### Шаг 2: Настроить API (опционально)

По умолчанию приложение работает в **тестовом режиме** с фейковыми данными.

Чтобы подключить к реальному серверу:

1. Открой файл **`AppConfig.kt`** 
   - Путь: `app/src/main/kotlin/com/colatracker/AppConfig.kt`

2. Измени настройки:

```kotlin
object AppConfig {
    // Установи false для работы с реальным API
    const val USE_MOCK_DATA = false
    
    // Укажи IP адрес твоего сервера
    const val BASE_URL = "http://192.168.1.100:8000"
    
    // Укажи токен из data.json на сервере
    const val AUTH_TOKEN = "cola_secret_token_2025"
}
```

**Как узнать IP адрес компьютера с сервером:**

- **Windows:** Открой командную строку → `ipconfig` → найди IPv4
- **Mac/Linux:** Открой терминал → `ifconfig` → найди inet
- Убедись, что телефон и компьютер в одной WiFi сети!

### Шаг 3: Запустить приложение

#### Вариант A: На реальном устройстве (рекомендуется)

1. **Включи режим разработчика на телефоне:**
   - Настройки → О телефоне → Нажми 7 раз на "Номер сборки"
   
2. **Включи отладку по USB:**
   - Настройки → Для разработчиков → Отладка по USB (вкл)
   
3. **Подключи телефон к компьютеру через USB**
   - Разреши отладку по USB на телефоне
   
4. **В Android Studio:**
   - В верхней панели выбери свое устройство в выпадающем списке
   - Нажми зелёную кнопку **▶️ Run** (или Shift+F10)

#### Вариант B: На эмуляторе

1. **Создай эмулятор:**
   - Tools → Device Manager → Create Device
   - Выбери модель (например, Pixel 6)
   - Выбери системный образ (API 34 рекомендуется)
   - Finish

2. **Запусти эмулятор:**
   - В Device Manager нажми ▶️ возле созданного устройства
   
3. **Запусти приложение:**
   - Выбери эмулятор в верхней панели
   - Нажми **▶️ Run**

### Шаг 4: Тестирование

#### Тестовый режим (USE_MOCK_DATA = true)

В приложении будут отображаться:
- 2 ребёнка с фейковыми данными
- Можно добавлять записи
- Можно удалять записи
- Всё работает без сервера

В левом верхнем углу будет надпись **"🧪 Тестовый режим"**

#### Реальный режим (USE_MOCK_DATA = false)

Приложение подключается к твоему серверу:
- Загружает реальных детей из data.json
- Добавляет/удаляет записи через API
- Требует, чтобы сервер был запущен

**Если появляется ошибка:**
1. Проверь, что сервер запущен (`uvicorn main:app --host 0.0.0.0`)
2. Проверь IP адрес в `AppConfig.BASE_URL`
3. Проверь, что телефон и компьютер в одной сети
4. Проверь токен в `AppConfig.AUTH_TOKEN`

## 🐛 Решение проблем

### Проблема: Gradle sync failed

**Решение:**
1. File → Invalidate Caches → Invalidate and Restart
2. Подожди 5-10 минут для загрузки зависимостей
3. Проверь интернет соединение

### Проблема: "Cannot resolve symbol..."

**Решение:**
1. Build → Clean Project
2. Build → Rebuild Project
3. File → Sync Project with Gradle Files

### Проблема: Устройство не видно в списке

**Решение:**
1. Проверь USB кабель (используй оригинальный)
2. Разреши отладку по USB на телефоне
3. Переустанови USB драйвера (для Windows)

### Проблема: Приложение вылетает при запуске

**Решение:**
1. Проверь логи: View → Tool Windows → Logcat
2. Ищи красные строки с ошибками
3. Если ошибка сети - проверь `AppConfig.BASE_URL`

### Проблема: "Unable to connect to server"

**Решение:**
1. Убедись, что сервер запущен: `uvicorn main:app --host 0.0.0.0`
2. Проверь IP адрес в `AppConfig.BASE_URL`
3. Телефон и компьютер должны быть в одной WiFi сети
4. Попробуй открыть в браузере телефона: `http://IP:8000/docs`
5. Если не открывается - проблема в сети, не в приложении

### Проблема: "401 Unauthorized"

**Решение:**
1. Проверь токен в `AppConfig.AUTH_TOKEN`
2. Сравни с токеном в `data.json` на сервере (поле `auth_token`)
3. Токены должны совпадать точь-в-точь
